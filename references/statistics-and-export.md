# 原生时间范围、原始CSV与可调存盘

## 当前正确API

| 对象/方法 | 已证语义 |
| --- | --- |
| SaveDataBrowser.DataRows | N为真实数据行数，不包含表头 |
| SaveDataBrowser.GetCellValue(int行,int列) -> string | 行0为表头；真实数据行1…N；本项目时间列为1 |
| 当前控件.SetTimeDialog | 原生同一个对话框中选择开始与结束；保留原生入口与私有筛选 |
| Refresh | 无返回值的原生方法，单独调用，不能赋值或把返回码当成功证据 |
| !ExportHisDataToCSV | 全局原始历史导出，启动返回与异步最终完成分开 |

**关键行号修复：**首条`GetCellValue(1,1)`，末条`GetCellValue(N,1)`。此前用`(0,1)`会得到标题“时间”（长度2），末条`N-1`也会漏最后一行。不要将这个错误解释成“用户没有勾选显示年月日”或盲目改显示选项。N=0不读取端点，返回空结果；空串是尚未就绪/缓存未到，格式不符另报无效时间。

原生`SetTimeDialog`一次选起止，不能拿历史曲线的`ShowTimeDialog`替代。历史曲线与存盘浏览是不同原生对象，名称相近不表示API等价。不能用“统计开始时间/统计结束时间”等旧全局变量假冒原生控件的私有筛选；原生对话框改了条件，旧变量可能毫无变化。

## 当前首末记录包络桥

当前工程用统计控件实际数据行的首末完整时间构成导出范围，准确名称是“准备时已有记录的时间覆盖范围/包络”。全局CSV没有获得native私有筛选完整状态；它不是原生精确起止的公开回读，也不是数据库事务快照。

准备态核对仍在统计页、N>0，读首末，复读N及两个端时间，再作最终N检查。保持当前时间排序及同一筛选，离页只取消准备态，不干扰已经启动的导出。读取不到、记录变化、格式无效就结束准备并准确提示，不扩到全历史，不循环等到凑够数据。

先验证19字符`YYYY-MM-DD HH:MM:SS`、分隔符、纯数字、闰年/月天数/时分秒，再用本实现的日期转换与完整回环校验。当前工程保守接受1971…2036年，以中国标准时间UTC+08且无DST为实施前提；这是本工程策略，不是“厂家只支持1971至2036”或其他时区通用结论。不要恢复1970午夜的有问题种子，也不凭推测断言厂商所有1970/2037日期都非法。

升序/降序取两个端时间的最小/最大。单条或同秒多条允许起止相同，不私加一秒；当前后端只拒绝start>end。数值列格式不参与时间判断。

本桥在固定记录集、仅时间筛选、时间排序前提下可以覆盖原有行；当前没有数值条件并不表示Stu版本不支持数值条件。持续写入时可能新增/删除记录，即使两轮端点一样也不保证成员集合不变；后加入而位于包络内的行可能被导出，位于包络外但仍属于原生原始范围的晚到行可能不在本次导出。不要宣称完全重放native所有私有谓词或原子冻结结果集。未来若加入数值条件/非时间排序，需要重新设计桥接或拒绝该模式。

## 两万行、原始数据与真实完成

本工程单次上限设置为20000条，这是方案参数，不是所有版本的厂商最大值。调用保持原始值导出，不能把显示格式化后的表格逐格写CSV冒充原始历史数据。当前实际调用形态：

```text
数据导出返回码 = !ExportHisDataToCSV(数据导出文件路径,"A压制存盘","",数据导出开始时间,数据导出结束时间,20000,1,"",数据导出进度,数据导出控制)
```

具体参数必须按当前厂商函数签名与真实对象注册核对，以上是本项目证据，不给其他版本自动背书。达到上限提示缩小范围分批导出；N仅用来定位末行，不能拿N代替全局上限来“补满下一批”。

启动返回0表示任务已开始。最终由原生传址控制/进度对象及实际回调决定完成；本项目策略52接收/轮询最终状态。`control=1`才走结束判定，同时检查取消标志及负错误码；不能凭文件存在、文件大小增长、固定延时或点了按钮就报“已完成”。取消状态独立保存，避免原生control复位1后误报成功。

每次生成唯一文件名并查重，不覆盖已有文件。路径准备、无U盘、目录不可写、取消、启动错误与最终错误各自准确报告。导出运行中允许切页面，但不要因页面已关而读取失效windowrefs。数据对象忙状态与原生任务控制应按实际生命周期更新。

## 可调历史存盘周期

本项目保存组`A压制存盘`，`历史存盘周期秒`按0.1秒粒度校验；当前方案范围0.1…3600秒，换算为0.1秒单位调用`!ChangeDataSave`。检查NaN、边界和粒度，失败不宣称生效。

应用成功后更新“生效周期”，`!SaveSingleDataInit(历史存盘周期秒)`及`!FlushDataInitValueToDisk()`分别检查返回码；“当前已生效但初值/磁盘保存失败”应与“全部保存完成”区别。启动策略恢复保存值，重启后核对实际周期。上述范围是本工程UI实施策略，不能泛化为厂商功能边界。

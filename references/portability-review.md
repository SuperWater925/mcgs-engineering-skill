# 换电脑与首次使用的可迁移性复查

本页保留前轮修复记录，各项范围限于当时所列入口，不能外推为所有消费分支或所有数量限制均已移除。当前逐项处理、容量与保留能力见[后续复查处理](compatibility-resolution.md)及[分项证据](compatibility-resolution-validation.json)。

本轮接续取消软件发行号、作者 EXE/DLL 整文件 SHA 白名单的工作，检查会让普通项目或不同安装布局被拒绝的其它条件。详细证据见[本轮隔离验证](pro-native-portability-validation.json)；此前取消指纹准入的记录见[构建准入验证](pro-native-build-admission-validation.json)。

## 仍可能阻止某项功能的实际条件

这些条件不应写成“必须升级到作者版本”，也不能删除后假称功能已适配。

- **真实 ABI 与模块。** 当前内部接口需要 Windows、x86 Pro、.NET Framework x86，以及匹配的函数、RTTI、虚表和对象布局。部分主模块查找仍使用原模块名。未知构建、被改名模块或不同布局需要对应实现；路径准备成功不证明业务可用。
- **未知控件与驱动。** 完整前像、引用和持久化扫描覆盖已有封闭类型；不认识的原生控件、设备驱动属性可能使整页/全工程扫描失败，即使它不是本次修改对象。须补实际读取和保全适配，不能跳过其它对象或删条件。当前驱动适配不是任意厂商协议生成器。
- **图库的专用读取界限。** 内嵌图片资源扫描仍采用递归实现，保留 16 层及 8192 图片的读取界限，向量帧列表还有 4096 帧界限。这些是该功能当前实现的范围，不是协议容量或软件版本要求；本轮没有扩展这条资源遍历，也没有宣称所有数量、深度界限均已消失。遇到超界应报告具体功能与实际数量。
- **模式与工厂范围。** Stu 在线未实现；Pro 离线 create 只有包内 800×480 空白工厂，既有工程编辑没有这个分辨率限制。离线基础控件工厂不等于任意控件增删。在线有视图时改页尺寸、删除非空/已引用页面等仍有未实现语义。
- **实际环境与容量。** 需要当前进程/COM/文件的实际权限及可用输出目录；不修改系统安全策略。当前路径实现对重解析/UNC 等有边界，运行路径仍有 UTF-16 长度限制。请求/回执有 16 MiB 等容量与 JSON 深度限制，数量配额移除不等于无限大工程支持。
- **原厂行为。** 保存、检查、重开可能显示原厂对话框。工程加密、密码、缺少字体/控件/驱动和原厂自身能力均要按实际情况处理。组态接口不包含设备下载和现场运行。

## 给首次使用者的判断顺序

先问离线或在线，用户已选则沿用。离线执行 doctor，在线执行 native-doctor 并明确实际安装根目录/EXE；MCGS_PYTHON 指定的解释器要贯穿所有步骤。在线 prepare 通过后才做连接，再逐项看业务接口是否适配；不要把连接成功或 ok=true 写成原厂检查通过。旧进程已经加载的桥不会因复制新版技能自动更新。

本轮生产源码编译、自有内存/managed 容器、部署链和自有消息环的结果分别记录。未在新电脑运行，未重做真实 Pro 工程写入、原厂检查、关闭重开或本机模拟；用户暂停的工程保持暂停。

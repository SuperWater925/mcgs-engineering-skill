# 离线图片库管理

在 `edit` 规格的顶层填写当前工程的 `source_sha256` 和 `picture_library` 数组。每个动作依次使用上一动作的结果。整组通过后写入新的工程副本。以下是两个动作的规格片段。

```json
{
  "picture_library": [
    {"action": "rename", "name": "图片85", "new_name": "泵站主画面"},
    {"action": "delete", "name": "未使用的末项"}
  ]
}
```

- 从普通图片新增时，使用 `{"action":"add","name":"泵图","image_hex":"…"}`。`image_hex` 填完整 BMP、PNG 或 JPEG 文件的十六进制内容。标准 24 位无压缩 BMP 使用原厂 kind 0。如果源 BMP 省略像素区长度，按原厂归档补写该长度。PNG、JPEG 和原有普通 BMP 封装使用 kind 2。新资源身份按归档头和编码字节的原厂摘要计算。
- 从供体新增时，使用 `name` 和 `resource_hex`。后者是供体工程中完整的原厂光栅资源明文归档，包含名称、原生资源身份、尺寸和编码字节。不同资源名可共享同内容的原生摘要。安全导出的 `System/MCGS_PICTURE_DATA_N/lbContext` 若有 MCGSZIPE 封套，先用 `mcgs_native_zip.unpack_if_wrapped` 解包。新增保留供体身份和像素，按目标格式追加索引。首次导入可建立库。
- `resources` 的 `raster_hex` 可为已存在的 kind 0 资源替换标准 24 位 BMP，也可替换已支持的 kind 2 光栅内容。替换保留原名、身份、类型和当前引用。
- 新建可编辑矩形图使用 `{"action":"add-vector-rectangle","name":"泵体图形","bounds":[20,30,145,110],"fill":2511546,"border":3158891}`。`bounds` 依次是左、上、右、下。`fill`、`border` 可省略，填写时用整数 COLORREF。按工程家族写 Stu 或 Pro 的单矩形原生 VECT 结构，使用原厂摘要计算资源身份。
- 新建可编辑线段图使用 `{"action":"add-vector-line","name":"水平线","bounds":[20,30,145,110],"endpoints":[138,70,28,70],"border":3158891}`。`bounds` 是正面积画布，`endpoints` 是画布内的两个有序端点，按原厂规则转换为万分比坐标。横线、竖线和斜线共用此格式。`border` 可省略，填写时用整数 COLORREF。结果是一个 CDrawCell 和一个 CDrawLine。
- 在同一个原生可编辑 VECT 中按顺序组合矩形和线段，使用 `{"action":"add-vector-shapes","name":"阀门及流向","bounds":[0,0,100,200],"shapes":[{"type":"rectangle","bounds":[10,30,90,120],"fill":2187828},{"type":"line","endpoints":[90,150,20,20],"border":3158891}]}`。每个矩形可指定可选填充色和边线色，每条线可指定边线色。图件在原生画布内保留顺序和线段方向。
- `rename` 需要现有精确名称 `name` 和新名称 `new_name`。原生位图、标准按钮、多状态按钮和多状态显示中的已知图片引用随名称同步，支持组内对象。比较完整的资源名，`图片2` 与 `图片21` 分别定位。其余数据库文本或不透明字段含有关联名称时停止，回执给出所在表或归档类别。
- `delete` 按精确名称删除，同时检查图片名及原生身份的残余引用。删除末项保留其余槽号。删除中间项要求图库外的工程记录与对应 Stu 或 Pro 空白母版一致。图库资源须为独立光栅，或为能够按现有工厂逐字节重建和核对身份的独立矩形、线段及其组合。通过后按顺序调整后续槽号，各图片的数据库行 ID、资源身份和图像字节保持原值。业务页、脚本及其他 VECT 结构需要另外核实槽号引用。

操作前后核对实际索引首计数、逐项名称、连续资源数据行和独立的四字节尾字段。Pro 原厂重开分别实测 20 个索引项、尾字段 19，以及 31 个索引项、尾字段 29。对此类既有索引，在同一离线事务保留尾字段原值。新图库及原先首尾相等的索引仍按对应布局更新。MCGSZIPE 和明文归档分别保持原有封装形式。实际副本离线改名通过全 12 表回读，原槽、图片数据和内容签名保持。

现有 VECT 的 `resources` 入口用图库键、资源摘要、子件路径及子件摘要定位。静态、无链接的原生内嵌位图子件可改 `bounds`，原图封装和全部图像字节保持原值，包括库存模板中的 VS 图像。可完整回读的 CDrawLabel 子件支持 `font` 中的 `height`、`weight`、`italic`、`underline`、`strikeout`，使用定长字体字段。用于核对标签结构的原厂模板子件标题为空。Pro 公共图库和 Stu 设备图库的原厂组件归档包含静态 CDrawLine；项目 VECT 内的线段子件沿用 `bounds:[x1,y1,x2,y2]` 读取和修改有序的局部端点。

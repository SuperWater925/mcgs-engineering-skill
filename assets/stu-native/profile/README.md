# Stu 在线原生角色定位

`locate.py` 从实际安装的编辑器生成当前进程使用的 ABI 资料。它只读取 PE 文件，原厂工程检查另由已经连接的引擎在编辑器线程中执行。

```powershell
python -B -X utf8 assets/stu-native/profile/locate.py --editor C:/McgsStu/Program/McgsSetStu.exe --out C:/Temp/stu-roles.json
```

`--out` 指定一个新的文件。省略时将 JSON 写到标准输出。`reference.json` 与脚本一起安装，包含经原厂调用和文件分析确认的类型、函数片段和字段布局。

- `capabilities` 对工程身份、页面和控件目录、组态检查、设计页读取与打开、批量编辑和模板复制分别报告 `verified` 或 `unknown`。`verified` 表示当前 PE 中该能力所依赖的角色和布局证据已匹配。运行时仍需核对实际进程、原生对象、编辑器线程和工程身份。
- `tables` 给出当前 PE 内的 RTTI、子对象偏移、定位器和已验证的虚表槽。`functions` 给出实际入口 RVA 和应复核的代码片段。代码片段中的照录字节使用此 PE 的首选基址，进程内比较时应在 `reloc_offsets` 记录的每个 HIGHLOW 项上加实际基址差。
- `layout` 仅列出已验证能力需要的成员偏移和存储范围。`image.sha256` 描述这次分析的文件，可以用来核对连接是否仍指向它。定位不依赖原研究编辑器的版本号或整文件指纹。
- `imports` 给出所用的 IAT 位置和导入符号。标签赋值使用实际加载的 MFC 字符串接口。引擎按模块和序号核对导出地址及 IAT 指针，再调用原厂赋值方法。
- 短函数优先通过 RTTI 虚表或已验证原厂调用定位。例如检查输出数组的计数和取项角色来自原厂 F4 检查调用路径，打开窗口的函数来自原厂用户窗口工作台调用。出现多候选或函数、调用范围、对象布局证据不符时，受影响的能力返回 `unknown`，其他能力独立报告。

设计页资料覆盖主框架、用户窗口模板、文档、实际子窗和原厂当前打开上限。打开角色独立于设计页读取。静态标签资料检查原厂控件基类构造的事件和动画容器。批量写入额外依赖原厂页和根修改标记、页和根保存、同一绘制视图的刷新接口。使用者仍须传入实际页和控件前像。

几何批量编辑共用顶层控件目录、设计页、刷新和保存能力。标签、输入框、标准按钮的几何方法单独定位。各方法经当前 RTTI 虚表的第 21 槽验证，接收四个有符号整数的 RECT 与空变换参数。原厂方法先规范化该矩形，再写入控件的四个边界字段。验收分别记录位置、尺寸和每个实际写入的控件类。

活动设计页的模板复制使用原厂绘制对象主表的第 28 槽，以及原厂粘贴调用的顶层插入。标签、输入框和标准按钮分别验证主表、绘图接口、原生序列化和私有对象析构。复制归档的忙状态地址取自实际编辑器中指向同一存储的置位及复位指令。设计文档的模式字段由原厂插入判断验证，当前支持直接插入的模式 0 和 1。保留输入绑定及标准按钮动作，以原生对象和文件分别核对。

默认控件创建共用原厂顶层插入，从当前工厂的跳转表分别定位标签、输入框及标准按钮的构造路径。每类单独核对原厂构造、默认成员和未收养对象的清理角色。新输入框保留原生空绑定及未分配的变量标记。新标准按钮保留原厂两态及各组默认动作字段。

整页新建和同工程复制分别验证用户窗口工作台的第 100 槽和第 92 槽。工作台原始标签选择、原有文档修改状态、原厂命名和保存共用角色。复制额外核对原厂内存文件、归档构造和析构导入，存档回绕时验证实际内存文件的 Seek 虚表槽及当前 MFC 导出。

同进程工程操作分别定位状态读取、原厂关闭和原厂打开。状态读取以应用与主框架为作用域，对照应用当前根和原厂全局根。全局根的指针槽由原厂发布及释放指令共同验证。关闭还核主控、设备、用户窗与策略模板及各自原厂修改状态。打开核应用原厂文件入口及进行中状态。两种操作均等待各自原厂调用返回，再校验实际根及工程路径。

配方模块按原生管理器、配方、列项和两个嵌入数组的 RTTI 验证布局。运行中另外核对 MFC 实际加载的 CStringArray、CByteArray 类型与序列化导出。单元格写入使用小范围原厂 Setter 和原厂单组保存。归档版本字取自经原厂单组写入路径定位的当前映像只读数据，记录前后实际版本字。

可见动画使用原厂 `CAniVisible` 的序列化、设置宿主和属性确认角色。控件反序列化将完整绘制对象交给动画，读取时复核实际拥有关系和原生动画数组。模式写入只更新经定位的模式整数，并按原厂属性确认行为设置所属控件修改标记的最低位。其余位与原表达式保持。

目前资料以本机 McgsStu 3.5.3.9198 SP1 x86 的实证建立。跨构建可重定位可辨识的角色。尚未提供其他实际 Stu 安装验证；对于更改了调用或私有布局的构建，应补相应角色证据。
